# Cuaderno de Guionista

Repositorio de sinopsis, biblias y guiones de Mario Alonso. La web pública (GitHub Pages) muestra el catálogo con estilo de máquina de escribir: una Home con cada título y su descripción, y una página por proyecto con el desarrollo de la sinopsis y el guion cuando lo haya.

| [Rejas](rejas/) | Thriller psicológico | Largometraje | Semilla |
| [Durante](durante/) | Drama | Largometraje | Semilla |

Ideas sin carpeta propia: [semillero](semillero/).

## Estructura

Cada carpeta de proyecto contiene su página web (`index.html`) y sus documentos de trabajo en Markdown: `sinopsis-breve.md` (una página, para enviar en frío), `sinopsis.md` (documento de venta completo) e `historial-versiones.md` (qué se descartó y por qué). Cuando el desarrollo avance se añaden escaleta, biblia y guion. El historial fino, línea a línea, lo guarda git. La hoja de estilos compartida de la web es `styles.css`.
